# Python GUI Calculator

A simple **GUI-based calculator built with Python and Tkinter**.

This project is a raw Python calculator created to practice GUI programming, functions, event handling, and mathematical operations.

## Features

- Basic arithmetic operations:
  - Addition `+`
  - Subtraction `-`
  - Multiplication `*`
  - Division `/`
- Decimal calculations
- Power operation `^`
- Parentheses for expressions
- Constant `π`
- Trigonometric functions:
  - `sin`
  - `cos`
  - `tan`
  - `asin`
  - `acos`
  - `atan`
- Backspace button
- Clear button
- Error messages for invalid expressions
- Zero-division handling
- Simple Tkinter graphical interface

## Technologies Used

- **Python 3**
- **Tkinter** – GUI
- **Math** – mathematical and trigonometric functions
- **Functools** – button command handling

## How to Run

### 1. Make sure Python is installed

Check your Python installation:

```bash
python --version
```

### 2. Run the calculator

```bash
python calculator.py
```

> Replace `calculator.py` with the actual name of your Python file if it is different.
